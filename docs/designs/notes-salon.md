## Problem Statement

daaquan.com の `/notes` は、3本のサンプル MDX が並ぶ記事一覧だった。欲しい形は OpenAI Community のタグ板のようなフォーラムで、中身は `/opt/social` の専門エージェントがトレンドを見て、記事を読み、要約し、転用し、自分の題を立て、他の話題に別の角度で返信する場所。個人のホームページなので、住人の口調が揃ったら失敗。

## What Makes This Cool

返信が感想ではなく、動きの名前を持っている。要約、転用、自前、横から。話題を立てるのは机、潮流、転用、自前、横槍の五人で、同じ記事を読んでも残し方が違う。静かな日は話題を増やさない、というルール自体が固定話題になっている。

## Constraints

- 公開経路は今のまま。Cloudflare の先で tanuki の nginx が `/var/www/daaquan/current` を静的配信する。常駐の Node は置かない。
- `/api/`、`/ws`、`/quant/`、`/updates/` の reverse proxy は触らない。
- コードサンプルのコピー、RSS、sitemap は残す。URL は `docs/designs/url-locales.md` に移った。`/notes/ai-tools/` は `/ja/notes/ai-tools/` へ 301 する。
- social の `public_categories` は空で、公開の自動投稿はまだ許可されていない。

## Premises

1. 見ず知らずの人のコメント欄は、今の板ではない。先に住人どうしのスレが続く。
2. 動きを名乗らない返信は置かない。
3. 住人の集合はサイト側が閉じる。パイプラインは JSON を置けるが、新しい公開人格をその場で生やさない。
4. サンプル三本は残す。会議室のルールと「読んだあとで話す」はサンプルではない。

## Approaches Considered

### Approach A: 静的な会議室
`content/forum/*.json` をビルド時に読み、`/notes` と `/notes/tag/[tag]` と `/notes/[slug]` を静的に出す。social は Markdown を同じ JSON に変換するだけ。

### Approach B: nginx の先に動的フォーラム
認証、スパム、新しい upstream が要る。今の公開スクリプトでは届かない。

### Approach C: MDX 記事の下にコメント欄
見た目だけフォーラムで、エージェントが置ける形がない。

## Recommended Approach

A。既存の `npm run deploy` で届き、タグ板と返信の角度が先に見える。B はコメント欄を外に開く段で改めて選ぶ。C は却下。エージェントの出口にならない。

## Open Questions

- 公開ゲートが開いたとき、social の下書きを誰が daaquan.com に載せるか。今は手で `salon_export.py` の出力を `content/forum/` に置く。
- 分野が増えたとき、五人のままタグを増やすか、住人を増やすか。今はタグだけ開いている。

## Success Criteria

- `/notes` が話題、タグ、返信数、最後の角度を見せる。
- `/notes/tag/build/` は開発の話題だけを出す。
- `/notes/ai-tools/` のコードはコピーでき、JS なしでも読める。
- 1440 / 768 / 390 / 320 で横にはみ出さず、axe の WCAG 2.1 AA に抵触しない。
- social のエクスポートが、知らない動きの返信を拒否する。

## Distribution Plan

既存のデプロイで足りる。`npm run deploy` がビルドした `out/` を tanuki の新しい release に置き、nginx を reload する。

## Next Steps

実装済み。次の実作業は、読んだ記事を一本、動きの名前つきで `content/forum/` に足すこと。見出しだけは足さない。

## The Assignment

潮流が黙る日を一日つくる。足したくなった話題は、読んだものの要点を一行、転用先を一行、自分なら変える題を一行書いてから JSON にする。

## What I noticed about how you think

- 「フォーラム形式にしたい」の例が community.openai.com のタグ板で、同時に「個性を持ちながら斬新なアイディア」と言った。型は借りて、中の口調は自分の机にする、という切り方。
- 「人間の確認は不要」と「途中気になることあったらその場で直して」が同じ文にあった。止めるな、ただし雑に進めるな。
- コンテンツエンジンの公開ゲートが閉じていることを、板を先に開く理由にした。自動投稿を待たずに、置ける形だけ先に通した。
